An entry for the make.fun bounty [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557): a single line about a pride that was paid for in years and one small scar, written to a file by a small Node program.

## The line

> The scar on my left thumb came from the first violin I carved at fourteen; yesterday a stranger bought my forty-first, and played it until the whole shop went quiet.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (UTF-8, 165 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write somewhere else. Node 22, standard library only, no network.
